Entertainment -App

A modern entertainment discovery web app built with React that helps users explore movies and entertainment content in an interactive, responsive interface. The app integrates external APIs to provide real-time data, search functionality, and categorized browsing.

Features

1. Browse Popular, Now Playing, Upcoming, and Top-Rated content
2. Search movies instantly with dynamic API fetching
3. Responsive UI for desktop and mobile
4. Clean component-based React architecture
5. Error handling and loading states for smoother UX
6. Structured API service layer for maintainability

Tech Stack
1. Frontend: React, JavaScript, HTML, CSS
2. API Integration: TMDB API
3. Tools: Git, GitHub, VS Code
